#  Reflection
* Overall Learnings
    * I used Canva to grab one monster and have it create variations.
    * This was the most I have used the LLM to create a much more complex app than we have been dabbling in this semester.
    * There is value in being able to manually edit your creation, especially for the overall styling and look of the app.
    * I started with the very bare bones of the app, making sure that everything was working functionally before implementing creative styling choices. It was looking a lot like the Reminders app, and I wanted to add more pizazz that would make the user interested in actually using this app.
    * Functionality is everything!
* Challenges
    * One challenge I had was figuring out how best to implement the “tomogachi-style” feature. I wanted a little monster that “eats” your tasks as you complete them, but throwing this request into the LLM gave me all kinds of errors. Instead, I had ChatGPT write me a thorough prompt that would give me the platform for the monster I wanted, but without all of the bugs. This provided me with a framework for the monster to sit in, and I went to Canva to create him.
    * ChatGPT kept running out, even after I upgraded to Premium. Most of my requests were fixing errors in the code, so it was difficult to try and balance how much I was using the LLM. 
* Next Steps
    * We are finished with this class, but I hope to carry the skills I learned working with an LLM into my EM degree and future career! I will also be using this app as a task tracker for my own life!
