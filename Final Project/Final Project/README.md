#  README
TASK MONSTER
* To begin, you can add a task to your task list. You can add a title and description as well as due date. Choose your category either from the predetermined list or your own custom category. These tasks can be set as a priority of either low, medium, or high. The lower the priority, the less the task satiates the monster and vice versa. As you cross items off of your list, the monster “eats” your tasks. When the hunger bar is half full, the monster will be satisfied. Get the bar all the way to full, and he is especially happy. The hunger bar resets every 24 hours, and you have the day to satiate the monster again.
